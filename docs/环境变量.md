# 环境配置说明

| 变量 | 作用 | 要求 |
| --- | --- | --- |
| TOPO_DB_URL | MySQL JDBC URL | 默认本机 topo；需已建库 |
| TOPO_DB_USERNAME | 数据库账号 | 最小必要权限 |
| TOPO_DB_PASSWORD | 数据库密码 | 必填，不提交 .env |
| TOPO_CONFIG_ENCRYPTION_KEY | 模型 Key 加密主密钥 | 必填随机值，备份后保持稳定 |
| TOPO_JWT_SECRET | 访问令牌签名密钥 | 必填，至少 32 字符随机值 |
| TOPO_ADMIN_PASSWORD | 首次创建 admin 的密码 | 首次部署必填，不改变已有账号密码 |
| TOPO_BOOTSTRAP_ENABLED | 初始化管理员和知识示例 | 本地首次启动 true |
| TOPO_SESSION_COOKIE_SECURE | HTTPS Cookie | 本机 HTTP false，HTTPS 部署 true |
| TOPO_UPLOAD_DIR | 上传存储目录 | 默认 uploads；部署时持久化 |
| TOPO_JPA_DDL_AUTO | 实体结构检查策略 | 默认 update；生产迁移后使用 validate |
| VITE_API_PROXY_TARGET | 本地前端 API 代理目标 | 默认 http://127.0.0.1:8080 |

API Key 通过管理端模型渠道录入并加密入库，不通过 README、SQL 或源码分发。生产部署需配置反向代理、HTTPS、数据库备份、SSE 超时及上传目录权限；当前提供的是可本地复现的源码，不是已部署的公网服务。
比赛部署：在后端进程环境中设置 TOPO_MODEL_KEY_PRIMARY 为供应商密钥；管理端渠道的 API Key 栏填写 env:TOPO_MODEL_KEY_PRIMARY。数据库只保存加密的引用名。多渠道可分别使用 TOPO_MODEL_KEY_ 开头的不同大写变量；仅为受信任的供应商地址配置对应密钥。更改环境变量后重启后端。
