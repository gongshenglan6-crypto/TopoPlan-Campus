# 网络工程知识示例

## 办公网分层
办公网络可采用核心、汇聚、接入分层。小型场景可合并核心与汇聚层。容量须依据并发、业务流量及预留量评估。

## VLAN 与访客隔离
财务、办公、服务器与访客无线分别规划 VLAN。访客只允许访问互联网，默认拒绝访问内部业务网。隔离还需防火墙或 ACL 配合，VLAN 本身不等于完整安全策略。

## 冗余
双核心分别承担关键设备上联；双链路配置 LACP 时须核对设备能力，避免将不支持跨机聚合的设备直接跨机捆绑。网关冗余可根据实际设备使用 VRRP。

## 无线与服务器区
AP 数量须通过现场勘测和容量估算确定，不以楼层数直接决定。服务器通过服务器区交换机接入核心，避免将所有服务器直接挂到防火墙。AI 输出需由网络工程人员复核后实施。
