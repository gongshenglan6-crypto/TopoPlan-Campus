## 上传现有本地仓库
本项目已推送 main 分支至 https://github.com/gongshenglan6-crypto/TopoPlan ，仓库为 Public。更新时请保留现有 .git 并继续正常提交、推送，已有提交记录无需重新初始化。

## bundle 恢复
将 TopoPlan-history.bundle 与其他材料分开存放。在终端使用 git clone TopoPlan-history.bundle TopoPlan 恢复仓库；恢复后 npm ci 和 Maven 会重新获取依赖。

## 重要提交边界
本地整理不能替代远程仓库可访问性、视频提交或赛事官网操作。原始开发历史在提供的目录中不可用，本包没有伪造历史。团队名称、成员及分工安排已根据参赛者信息填写，正式提交前应由团队共同复核。
