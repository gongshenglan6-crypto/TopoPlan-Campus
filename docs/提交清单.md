| 要求 | 当前状态 | 提交前动作 |
| --- | --- | --- |

## 上传现有本地仓库
本项目已推送 main 分支至 https://github.com/gongshenglan6-crypto/TopoPlan-Campus ，仓库为 Public。更新时请保留现有 .git 并继续正常提交、推送，已有提交记录无需重新初始化。

## bundle 恢复
提交目录内的 TopoPlan开发历史.bundle 可恢复离线仓库。切换到该文件所在目录，执行 git clone --branch main './TopoPlan开发历史.bundle' './TopoPlan恢复副本'。目标目录应不存在。恢复后按 README 安装依赖。用 git bundle list-heads './TopoPlan开发历史.bundle' 与 git -C './TopoPlan源码' rev-parse HEAD 核对版本；公开仓库 main 分支应为同一提交。

## 重要提交边界
本地整理不能替代远程仓库可访问性、视频提交或赛事官网操作。原始开发历史在提供的目录中不可用，本包没有伪造历史。团队名称、成员及分工安排已根据参赛者信息填写，正式提交前应由团队共同复核。
